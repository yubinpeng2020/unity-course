网格与材质

理解 Mesh 网格与 Material 材质，会更换 / 添加材质、设置 Albedo，并调出属于自己的天空盒
授课教师彭堉斌
学校汕头职业技术学院

学习目标

🎯区分渲染模式（着色 / 线框 / 着色线框）
🔍理解 Mesh 网格是什么（顶点 + 法向）
📝掌握材质 Material 的创建、更换、拖拽切换，会用 Albedo / Metallic / Smoothness / Tiling 调整外观
🧱会用纹理包制作 PBR 材质：设置反射率 / 高度 / 法线贴图，做出地板等效果
🌤️会创建 Procedural 天空盒材质，并调整 Sun Size、Exposure 等参数
🌍会用 HDRI 全景图制作真实天空盒并应用到场景
网格决定"形状"，材质决定"皮肤"，天空盒决定"环境"。学完本节，就能用免费资源网站美化和装饰自己的场景。

渲染模式

Scene 视图左上角下拉框，控制场景的显示方式：

Shaded（着色）：正常实体显示，能看到材质颜色与光影

Wireframe（线框）：只显示网格线框，看物体结构

Shaded Wireframe（着色线框）：实体 + 线框叠加

💡 想看清楚一个复杂模型的"骨架"时，切到 Wireframe 最直观。

Mesh 网格

Mesh（网格） 是 3D 物体的"形状骨架"，由两部分定义：

  • 顶点坐标（Vertices）：空间中一个个点，连成三角面
  • 面的法向（Normals）：每个面朝哪，决定光照从哪边亮

网格的精细程度由顶点数 / 三角面数决定：

  • 面数越少：模型越"棱角分明"，性能开销小（如立方体只有 6 个面）
  • 面数越多：模型越光滑圆润，但更耗性能（如球体由大量三角面拼成）

为什么都用三角形？

  • 三角形是平面，三个点永远共面，不会"扭曲"
  • 四边形可能弯曲变形（四个点不在同一平面），游戏引擎无法渲染

法向 = 每个面的"朝向箭头"。光线从上方照下来时：

  • 法向正确：朝上的面迎光→亮，朝下的面背光→暗，看起来正常
  • 法向反了：朝上的箭头被翻转朝下→引擎认为它背光→该亮的面变暗，整个模型"发黑"

常见原因：从建模软件导出时法向被翻转、手动编辑网格误操作。Unity 里可用 Recalculate Normals 重新计算修复。

网格在哪看？

选中 3D 物体后，Inspector 里有两个配套组件：

  • Mesh Filter（网格过滤器）：持有"用哪个 Mesh"的引用 — 决定形状
  • Mesh Renderer（网格渲染器）：决定"怎么画出来"（材质、阴影、光照）— 决定外观

少了 Filter 不知道画什么形状，少了 Renderer 画不出来。Filter 给形状，Renderer 给皮肤。

Mesh 是"骨架"（形状），Material 是"皮肤"（颜色 / 光影）。同一个立方体 Mesh，换上不同材质就能变成木头、金属、玻璃。

Material 材质

Material（材质） 决定物体表面的"光学特性"：

  • 颜色、金属 / 非金属、光滑 / 粗糙、透明 / 半透明 / 不透明、凹凸……

更换材质

游戏对象的材质可以替换。选中材质时会有阴影效果，点击右下角的 选择材质 按钮弹出"选择材质"窗口。

添加材质

  • 资源放置在 Assets 文件夹内
  • 在 Project 窗口创建新文件夹（如 Materials）归类
  • 右键 Create（创建） → Material（材质） 新建一个材质
  • 命名（如 black）

修改 / 选用材质

  • 材质拖拽到物体上即使用
  • Albedo（反照率） 就是材质的"基础颜色"，点开色板就能改
  • 点击选择材质，即可查看其属性并设置

游戏对象材质可直接拖拽切换

游戏对象材质可直接拖拽切换。

多个自定义材质拖拽切换

有多个自定义材质，都可直接拖拽到游戏对象上切换。

精准设置

  • 场景中多个游戏对象时，直接拖拽材质到 Inspector 的材质框最为精准，不会误伤别的物体
  • 点击右下角的 选择材质 按钮弹出窗口，也可看到创建的材质
💡 颜色用 Albedo 调；要更真实就调 Smoothness（光滑度）和 Metallic（金属度）。

Shader 着色器

什么是 Shader（着色器）？

Shader（着色器）是决定"怎么把表面画出来"的程序——它定义了 Material（材质）背后使用什么属性来计算光照、颜色和纹理。

换个理解方式：

  • Shader = 一套"属性模板"（决定面板上有哪些参数可调）
  • Material = Shader + 你填入的具体参数值（颜色、贴图、数值）
  • 同一个 Shader 配不同参数 = 不同材质（如同一个 Standard，一个做木头、一个做金属）
  • 换 Shader = 换一套完全不同的属性面板

Unity 常用内置 Shader

在材质 Inspector 面板顶部点击 Shader 下拉框，可以看到 Unity 内置的所有着色器。下面重点讲两个最常用的：Standard 和 Skybox/Procedural。

⭐ Standard Shader

Standard（标准着色器）是 Unity 默认的基于物理渲染（PBR）的着色器，能模拟石头、木头、玻璃、塑料、金属等几乎所有真实材质。

Rendering Mode（渲染模式）

控制物体的透明方式，是 Standard Shader 的第一个参数：

模式效果适用场景
Opaque（不透明）默认，完全不透明石头、木头、金属
Cutout（镂空）硬边透明，无半透明区域树叶、铁丝网、破布
Transparent（透明）逼真透明，保留高光反射玻璃、透明塑料
Fade（渐隐）连高光一起淡出全息图、幽灵、淡入淡出动画

Transparent vs Fade：Transparent 的玻璃仍有清晰的高光反射，Fade 则整体变淡包括高光。

Albedo（反照率）

物体的基础颜色，可以选纯色或贴一张颜色贴图。也包含透明通道（Alpha），配合 Transparent 模式做透明效果。

Metallic（金属的）

0 = 非金属（塑料、木头），1 = 纯金属（铁、金）。中间值可以做半金属质感（如生锈的铁）。可贴金属度贴图实现局部金属区域。

Smoothness（平滑度）

0 = 粗糙漫反射（如岩石），1 = 镜面反射（如镜面金属）。决定表面反光的锐利程度。可贴光滑度贴图实现局部差异。

Normal Map（法线贴图）

制造表面凹凸细节，不改变模型形状，只改变光照计算。蓝紫色图像，让平面看起来有雕刻、划痕、砖缝等纹理感。

Height Map（高度贴图）

视差贴图，比法线贴图更有深度感（视角变化时会有位移效果），但更耗性能。灰度图，白色凸起、黑色凹陷。

Occlusion（遮挡）

让缝隙和死角更暗，增强立体真实感。灰度图（AO 贴图），白色=受光、黑色=遮蔽。

Emission（发射）

自发光颜色和强度，可做霓虹灯、屏幕、光芒等效果。勾选后可设置发光颜色和亮度，超过 1 的强度会触发 HDR 辉光效果。

Detail Mask / Map（细节遮罩）

近距离叠加更细的纹理细节（如近看木纹更清晰）。Detail Mask 控制哪些区域显示细节贴图，Detail Map 是细节纹理本身。

PBR 贴图效果 — 同一模型不同贴图对比

Standard Shader 的强大之处在于贴图驱动：不需要换模型，只换贴图就能改变材质外观。一组完整的 PBR 贴图通常包含：

  • Albedo Map（颜色贴图）→ 物体本身的颜色和图案
  • Normal Map（法线贴图）→ 表面凹凸细节（蓝紫色图）
  • Metallic Map（金属度贴图）→ 哪些部分是金属、哪些不是
  • Roughness/Smoothness Map（粗糙度贴图）→ 哪些部分光滑、哪些粗糙
  • AO Map（环境光遮蔽贴图）→ 缝隙和角落的阴影
💡 老师演示：新建一个立方体，把默认材质换成 brick_floor（砖地板）材质，观察立方体表面从默认灰白变成砖块纹理的过程；学生实操：用老师给的纹理包亲手做出这个材质。

课堂实操：用老师给的纹理包做 PBR 材质

  • 第一步：把老师提供的纹理材料 brick_floor_04_2k.blend 拖拽到 Materials 文件夹
  • 第二步：在 brick_floor_04_2k.blend/textures 文件夹下创建新的材质
  • 第三步：把三个贴图依次设置给对应属性：
    • brick_floor_04_diff_2k.jpg → 反射率（Albedo）
    • brick_floor_04_disp_2k.png → 高度贴图（Height）
    • brick_floor_04_nor_gl_2k.exr → 法线贴图（Normal Map）
💡 平滑度（Smoothness）没有独立贴图槽：砖地板整体粗糙，这里不用贴图，直接在材质面板把 Smoothness 滑块 调到 0.1~0.3 即可。纹理包里的 roughness（粗糙度）贴图是做精细控制用的，本课了解即可。
  • 第四步：选中立方体，用 Scale 工具 设置缩放：X = Z = 20、Y = 0.1，压成一块大而扁的板，再用 Move 工具 把它移到场景地面位置，作为一块大地板使用。
  • 第五步：选中材质，在 Inspector 找到贴图的 Tiling（正在平铺） 属性，调整 X 和 Y 的数值（如 5~10），调到贴图在地板上看起来自然舒服即可。
💡 Tiling（正在平铺） 控制贴图在表面上重复的次数：X、Y 数值越大贴图越密。立方体拉伸得越大，Tiling 也要相应调大，才能保持砖块大小自然。

免费 PBR 贴图资源网站（CC0 许可，可商用）：

  • ambientCG — 最大免费 CC0 PBR 贴图库，3000+ 组材质，8K 分辨率
  • Poly Haven — 高质量免费 PBR 贴图 + HDRI + 3D 模型
  • FreePBR — 600+ 免费 PBR 材质包

天空盒 SkyBox

什么是天空盒材质

天空盒（Skybox）是罩在场景外面的背景球，决定了场景的天空背景。

我们在课件4「天空盒 SkyBox」已经讲过天空盒的基础内容（默认天空盒、如何查看），本页接着做实操。Unity 提供多种天空盒 Shader，最常用的是 Skybox/Procedural（程序化天空盒）：不依赖贴图，通过调节参数就能直接生成天空效果。

  • 程序化（Procedural）：创建新项目时，场景默认的天空盒就是它——不依赖贴图，用参数直接生成天空（本页实操一）
  • 纹理化（Textured）：用真实图片（如 HDRI 全景图）做天空背景（本页实操二）

课堂实操一：创建程序化天空盒（Procedural）

  • 操作 1 · 创建新的天空盒材质：在 Project 窗口右键 → Create → Material，新建材质并命名为 Sky_Procedural，把 Shader 设为 Skybox → Procedural（程序化），材质上出现程序化天空盒的属性面板。

Skybox Procedural 参数分析

Skybox/Procedural 材质面板上有 6 个常用参数，逐个看下：

Sun Size（太阳大小）

控制天空中太阳的视觉大小。0 = 看不到太阳，1 = 太阳占据大片天空。通常设 0.04~0.1 较为自然。

Sun Size Convergence（太阳收敛）

控制太阳边缘的柔和程度：值越大，太阳边缘越锐利；值越小越柔和、过渡越自然。

Atmosphere Thickness（大气厚度）

模拟大气层的厚度。0 = 无大气（太空感），1 = 厚大气（地面感）。值越大，天空越蓝、日落色彩越浓郁。

Sky Tint（天空色调）

天空的整体颜色倾向。默认蓝色，可以改成紫色做异世界、橙红色做黄昏。

Ground Color（地面颜色）

地平线以下区域的颜色。默认深色，模拟地面反射。可以调成浅色做水面反射效果。

Exposure（曝光度）

天空整体亮度。0 = 全黑，1 = 正常亮度，>1 = 过曝。配合 Directional Light 的强度调整场景氛围。

  • 操作 2 · 设置新的天空盒：点击顶部导航栏 Window（窗口）→ Rendering（渲染）→ Lighting（照明），切换到 Environment（环境） 标签页，把 Sky_Procedural 材质拖进 Skybox Material（天空盒材质） 槽，场景背景立即变成程序化天空。
  • 操作 3 · 修改天空盒参数看效果：选中 Sky_Procedural 材质，调整 Sun Size（太阳大小）、Exposure（曝光度）、Sky Tint（天空色调） 等滑块，观察场景天空随之变化，找出自己喜欢的效果。
💡 Procedural 天空盒不依赖图片，调几个滑块就能换一整天色，课堂最方便。

课堂实操二：添加 HDRI 资源，设置真实天空盒

  • 操作 1 · 导入 HDRI 资源：把老师提供的 golden_gate_hills_2k.hdr 拖进 Project 窗口的 Assets 文件夹 导入。
  • 操作 2 · 创建天空盒新材质：右键 → Create → Material，新建材质并命名为 Skybox_HDRI，把 Shader 设为 Skybox → Panoramic（全景）。
  • 操作 3 · 设置天空盒新材质：把 golden_gate_hills_2k.hdr 拖到材质的 Spherical (HDR) 属性槽，材质预览上立刻出现真实天空贴图。
  • 操作 4 · 应用到场景：打开 Window（窗口）→ Rendering（渲染）→ Lighting（照明），切换到 Environment（环境） 标签页，把 Skybox_HDRI 材质拖进 Skybox Material（天空盒材质） 槽，场景背景立即变成真实天空。
💡 对比：Procedural 用滑块生成天空（不需要图片），Panoramic + HDRI 用真实照片（更逼真）。两种材质都能在 Lighting 窗口直接替换。

作业 — 下载免费资源美化场景

📌 本次作业用免费资源网站 Poly Haven 下载贴图和 HDRI，美化自己的场景：作业一给基础模型贴图，作业二给天空盒换真实天空。

Poly Haven 免费资源网站

打开浏览器访问 https://polyhaven.com，这是一个完全免费（CC0）的 3D 资源网站，可以下载贴图（Textures）、HDRI 和模型（Models）。

作业一：下载贴图，实现地板

从 Poly Haven 下载一张地板类贴图（如 Wood 木头、Brick 砖块），按课堂实操的步骤做出一个地板：导入贴图 → 创建材质并设置贴图 → 立方体压扁成地面 → 调整平铺（Tiling）。

  • 步骤一：在网站顶部点击 浏览 贴图（Textures）
  • 步骤二：在贴图列表里任选一个地板类贴图资源（如 Wood 木头、Brick 砖块等）
  • 步骤三：进入详情页，点击 Download（下载），分辨率任选（如 1K / 2K）。下载完成后导入 Unity，做成一块地板

作业二：下载 HDRI，设置给天空盒

从 Poly Haven 下载一张 HDRI 全景图，导入 Unity 后做成天空盒材质，应用到场景。

  • 步骤一：在网站顶部点击 浏览 HDRI
  • 步骤二：任选一个 HDRI 资源（如阳光、日落、夜景场景）
  • 步骤三：进入详情页点击 Download（下载），分辨率任选，格式选择 .hdr。下载完成后导入 Unity，做成天空盒材质应用到场景
💬 验收标准：地板上出现清晰贴图纹理，场景天空变为真实 HDRI 天空；能说出自己下载的分辨率并说明为什么这样选。
