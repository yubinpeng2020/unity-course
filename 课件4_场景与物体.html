场景与物体

认识 Unity 六大视图，学会创建与管理 3D 物体，理解摄像机、光源与天空盒
授课教师彭堉斌
学校汕头职业技术学院

学习目标

🔍能在层级视图中用两种方法新增 3D 物体（菜单栏 / 右键）
📦认识五种原生物体（Cube / Sphere / Capsule / Cylinder / Plane）及各自用途
📝能对物体进行命名、复制、删除操作，养成见名知意的命名习惯
📷理解主摄像机与定向光的作用，能新增摄像机和光源
🌄了解天空盒的作用，知道如何打开照明面板替换天空背景
✅知道 Grid 栅格是编辑器辅助线，运行时不显示

界面快速回顾

六大视图

  • Scene 场景视图：编辑物体的主舞台，可以看到整个 3D 世界
  • Game 游戏视图：模拟玩家视角，预览游戏运行效果
  • Hierarchy 层级视图：列出场景中所有物体，管理父子关系
  • Project 项目视图：存放所有资源文件（模型、贴图、脚本）
  • Inspector 检视视图：查看/修改选中物体的属性与组件
  • 工具栏 + 菜单栏：常用操作入口
💡 记忆口诀：Scene 是"世界"，Game 是"眼睛"，Hierarchy 是"目录"，Project 是"仓库"，Inspector 是"属性面板"。

新增物体 — 添加立方体

方法一：菜单栏添加

  1. 点击菜单栏 GameObject（游戏对象） → 3D Object（3D对象） → Cube（立方体）
  2. 一个立方体立刻出现在场景中

方法二：右键添加（推荐）

  1. 在 Hierarchy 层级视图 空白处右键
  2. 选择 3D Object（3D对象） → Cube（立方体）
  • Hierarchy 层级视图又名节点管理器
  • 场景中每一个物体，都会在层级视图中对应一个结点
  • 新增的物体自动出现在层级视图列表末尾

物体出生地：视野中心

  • 新增物体默认出现在视野中心附近
  • 移动视野后，新物体仍会出现在场景原点附近（而不是新的视野中心）
🎬 操作演示：连续创建多个物体，观察它们都出现在同一位置。

让物体回到视野中心：按 F

  • 在 Scene 视图中选中物体，按键盘 F 键，摄像机自动聚焦到该物体
  • 视野"飞"到物体旁边，方便查看
因为新物体默认生成在场景原点附近，而编辑器视野默认看向原点，所以"看起来"正好在视野中心。

原生物体 — 3D Object

Unity 内置了多种基础 3D 物体，无需任何素材即可创建：

物体说明外观
Cube 立方体长宽高相等的六面体
Sphere 球体光滑的球
Capsule 胶囊体圆柱+半球组合，常用于人物
Cylinder 圆柱体柱状体

Plane 平面 — 单面薄片

  • 只有单面，常用于地面、地板
  • 从侧面几乎看不见，适合做基座

处理物体 — 修改命名 / 删除 / 复制

2.1 修改命名

  1. 在层级视图中右键物体 → 选择 Rename（重命名）
  2. 输入新名称，按回车确认
  3. 养成"见名知意"的习惯：Wall、Player、Enemy，不要叫 GameObject (1)

2.2 删除物体

  • 选中物体后按 Delete 键（Mac 为 Fn + Delete）
  • 或在层级视图右键 → Delete（删除）
  • ⚠️ 删除不可撤销，操作前想清楚

2.3 复制 / 粘贴

  • 快捷键：Ctrl + C 复制，Ctrl + V 粘贴（Mac 为 Cmd + C / V）
  • 或右键 → Copy（复制） / Paste（粘贴）
  • 复制出的物体会出现在场景中，名称自动加后缀 (1)

摄像机 · 光源 · 新增

  • Main Camera 主摄像机 = 用户的眼睛
  • Game 游戏窗口中看到的内容，就是摄像机"看"到的内容
  • 新建场景默认自带一台主摄像机

移动摄像机，改变视角

  • 在 Scene 中选中摄像机物体，用移动工具拖动
  • Game 窗口中的画面会跟着改变
会看到一片黑屏或空白——因为没有任何"眼睛"在观察场景。

定向光 Directional Light = 太阳

  • 光从无穷远处平行照射，场景物体都会受光
  • 新建场景默认自带一束定向光

有平行光源

无平行光源

删掉光源后，场景会变暗/变黑（新物体呈现暗色，材质颜色无法正确显示）。所以光源是场景中不可或缺的"太阳"。

新增摄像机与光源

新增摄像机：菜单栏 GameObject（游戏对象） → Camera（摄像机）

新增光源：菜单栏 GameObject（游戏对象） → Light（光源） → Directional Light（平行光）（或 Point Light（点光源） 等）

💡 一个场景可以有多台摄像机、多个光源。多摄像机可以切换视角，多光源可以实现丰富的照明效果（本课先用默认的单机单光即可）。

天空盒 SkyBox

天空 与 地面：场景除了物体，还有头顶的天空背景和脚下的地面参考

什么是天空盒？

  • SkyBox 天空盒：包裹整个场景的背景，像一张巨大的"天空贴图"
  • 默认天空盒是蓝色渐变，看起来像白天

替换天空盒

想换一个天空背景？操作步骤：

  1. 菜单栏 Window（窗口） → Rendering（渲染） → Lighting（照明）
  2. 打开 Environment 环境 面板
  3. 找到 Skybox Material，点击圆点选择新的天空盒材质
💡 默认天空盒材质在 Assets 里看不到？可以先从官方资源包或 Asset Store 下载天空盒素材（第 8 课"网格与材质"会详细介绍材质与资源导入）。

场景辅助 — Grid 栅格

  • Scene 场景视图中灰色的网格叫 Grid 栅格，是 Unity 编辑器提供的辅助参考线
  • 栅格帮助判断物体位置与间距，运行时不会显示在游戏中
  • 在 Gizmos 菜单 里可以控制网格显示：选择 X / Y / Z 平面、调整不透明度、定位网格原点
因为 Grid 只是编辑器提供的辅助参考线，不属于游戏世界，不会渲染到游戏中。

课堂练习 — 创建你的第一个场景

要求

  1. 在上节课创建的 MyUnityLab 工程中，依次创建 Cube 立方体、Sphere 球体、Capsule 胶囊体、Cylinder 圆柱体（共 4 个物体，不含 Plane 平面）
  2. 给每个物体修改命名（如 MyCube、MySphere…），不要用默认名
⚠️ 重要提醒：这些物体是后续课程的操作对象——下节课会给它们移动位置，请保留好这个场景。
