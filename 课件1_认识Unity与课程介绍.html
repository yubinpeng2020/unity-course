什么是游戏

约翰·赫伊津哈《游戏的人》（1938年）：游戏是"没有明确意图、纯粹以娱乐为目的的所有活动"。

游戏的本质：以自愿自由为前提、以快乐自足为目的、具有规则的行为活动。

🎯 游戏五共性（沃尔夫冈·克雷默）

共性含义例子
🤝 共同经验玩家对规则的集体认知象棋的"楚河汉界"
⚖️ 平等规则对所有参与者一致约束篮球的"走步违例"
🕊️ 自由玩家自主决定是否参与积木随时可停
🧠 主动参与以主观意愿投入思考《我的世界》自由建造
🌍 游戏世界独立于现实的规则体系游戏内的货币/逻辑

📋 游戏四要素

  • 道具与规则：物质载体与行为约束（《塞尔达》大师之剑对盖侬特效）
  • 目标：驱动玩家行为（《刺客信条》同步率）
  • 进程变化性：对抗确定性的随机设计（《炉石传说》随机卡牌）
  • 竞争性：胜负机制的情感激励（《王者荣耀》推塔胜利）

电子游戏分类

你们对游戏都不陌生，但"游戏是怎么被造出来的"才是本课要回答的问题。先看看你玩过的游戏都属于哪些类型——每一类，背后都对应引擎的一组核心能力。

🎮 按玩法核心分类

类型说明代表游戏对引擎能力的侧重
🗡️ RPG 角色扮演剧情推进 + 角色成长原神、崩坏：星穹铁道动画、资源管理、剧情系统
⚔️ ACT 动作操作手感与战斗反馈永劫无间、黑神话：悟空物理、动画、打击感
🏎️ 竞速 RAC速度感与车辆操控极品飞车、QQ飞车物理、渲染
🏗️ 模拟 SIM拟真经营 / 生活模拟城市、动物森友会逻辑、AI
🧩 冒险 AVG解谜与叙事塞尔达传说、原神关卡、交互
🏀 体育竞技 SPG体育规则对抗FIFA、和平精英物理、动画

🔗 游戏类型 ↔ 引擎能力

  • RPG 需要动画系统 + 资源管理 → Unity 的 Animator、Addressables
  • ACT 需要物理系统 + 动画 → Unity 的 Rigidbody、物理材质
  • 竞速 / 体育 需要刚体物理 + 渲染 → Unity 的 WheelCollider、URP/HDRP
  • 模拟 / 冒险 需要逻辑 + 交互 → Unity 的 C# 脚本、UI 系统
💡 不管什么类型，背后都跑在同一套引擎能力上——渲染、物理、动画、交互。你学的 Unity，就是造这些游戏的"工厂"。下一节我们就看这台"工厂"到底是什么。

什么是游戏引擎

"引擎"（engine）最早出现在汽车领域，是汽车的动力来源，好比心脏，决定着汽车的性能和稳定性。计算机游戏也是如此——玩家体验到的剧情、关卡、美工、音乐、操作等内容，都由游戏引擎直接控制。

💡 光影效果实时光追《赛博朋克 2077》

🎯 物理系统刚体模拟Havok 引擎

Unity3D 互动引擎

🎯 Unity 是什么

Unity3D 是一款功能强大的游戏开发工具和互动内容创作平台。

✨ 四大特点

  1. 完整的游戏功能：从建模到发布一站式
  2. 强大的编辑器：可视化编辑 + 丰富的第三方插件
  3. 简洁的 SDK：C# 接口友好，学习曲线平缓
  4. 跨平台发布：Windows、Mac、Linux、Android、iOS、WebGL……

这些大作都是 Unity 开发的：

🎮 Unity 管场景和渲染，C# 管逻辑和行为。

🖥️ 渲染管线🤖 AI 行为
🎬 动画系统📊 游戏规则
📦 资源管理🖱️ 界面交互
能。本课程会带你从 Unity 语境直接学习 C# 核心语法——边做游戏边学编程，不要求你先系统学过 C#。C# 是地基，Unity 是房子：地基打牢，楼才盖得高。
