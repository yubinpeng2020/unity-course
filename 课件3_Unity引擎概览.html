Unity 引擎概览

认识 Unity 编辑器界面，学会创建项目、切换中文、理解菜单栏与六大视图，掌握场景视图的坐标系与常用工具
授课教师彭堉斌
学校汕头职业技术学院

学习目标

🎯能创建并打开一个 Unity 工程（纯英文路径），遇到 H0007 报错能按步骤修复
🔍能将 Unity 编辑器切换为简体中文界面
📝认识菜单栏六大菜单（File（文件）/ Edit（编辑）/ Assets（资源）/ GameObject（游戏对象）/ Component（组件）/ Window（窗口））的作用
💻能说出六大视图（Scene / Game / Hierarchy / Project / Inspector / 工具栏）各自的作用
✅理解左手坐标系与 Gizmo 导航器，掌握场景视图的变换工具、Gizmo 坐标系工具与显示开关，会用播放工具（运行 / 暂停 / 单帧）测试游戏

创建项目

每次上课打开实训室电脑，都要重新创建或打开项目。

① 打开新建项目窗口

  • 打开 Unity Hub，点击「项目」→「新项目」

② 选择模板与设置路径

  • 选择模板（课程统一使用 3D Core）
  • 设置项目名称与存放位置
  • ⚠️ 路径必须是 纯英文（中文或空格会导致后续打包、脚本报错）

③ 创建项目

  • 点击「创建项目」，等待进度条完成
  • 💡 黄色报警信息一般可忽略，不影响使用
如果关闭这个界面，怎么重新打开呢？

打开已有项目

每次重启实训室电脑，都会重新安装 Unity Hub。安装好后，需要在 Unity Hub 中重新打开之前创建的项目。

① 点击「项目」→「打开」

  • 启动 Unity Hub，点击左侧「项目」→ 点击右上角「打开」

② 选择项目文件夹

  • 找到并选中之前创建的项目文件夹（如 My Project），点击「打开」
  • 首次打开某项目会加载初始界面（Project 视图 + 场景），这就是工作起点

界面全是英文看不懂？→ 切中文

课程统一使用 简体中文 界面，避免中英混看。后续截图均基于中文界面。
两种方法，取决于编辑器是怎么安装的。

① 方法一：通过 Unity Hub 在线安装时勾选模块

  • 适用场景：照着课件2「安装 LTS 编辑器（在线安装）」操作
  • 第一步：在「安装」页面，点击编辑器右侧的设置按钮（⚙️），点击「添加模块」
  • 第二步：勾选「简体中文」，点击「安装」

② 方法二：本地已有编辑器，手动放置语言包

  • 适用场景：本地安装包 安装的编辑器（课件2「安装 LTS 编辑器（本地安装包）」）；或安装时忘了勾选中文
  • 第一步：在 Unity Hub 编译器配置页面，点击编译器右侧的设置图标 → 「在Finder中显示」
  • 第二步：将老师提供的 zh-hans.po，放到 Unity 编译器安装目录下的 Editor/Data/Localization/ 文件夹中，重新打开编辑器即生效

创建项目时报错 H0007

每次打开实训室电脑，配置好编译器后，创建或打开项目都会报错 H0007。这是实训室环境必遇的问题，按下面步骤修复即可。

① 打开编译器所在文件夹

  • 在 Unity Hub 编译器配置页面，点击编译器右侧的设置图标（⚙️）→「在资源管理器中显示」
  • 可以看到打开了 Unity 2022.3.xx/Editor 文件夹

② 打开终端

  • 在 Editor 文件夹的地址栏输入 cmd，回车打开命令行

③ 在终端执行修复命令

  • 在命令行中输入以下指令并回车：
  hasp_update.exe u unity-sl.v2c
  • 执行完毕，即可正常创建 / 打开项目
💡 这个命令需要在每次重启实训室电脑，设置编译器后执行一次，后续打开同一项目不再报错。

编辑器界面区域总览

在深入菜单和视图之前，先看一眼整个编辑器的布局——知道各个区域在哪，后面才好找。

Unity 编辑器默认布局分为五大区域：

位置区域作用
顶部菜单栏 + 工具栏菜单操作入口，变换工具、播放控制
中左Hierarchy 层级视图场景中所有物体的列表
中央Scene 场景视图3D 世界主舞台，布置和编辑物体
左下Project 项目视图所有资源文件的仓库
右侧Inspector 检视视图查看/修改选中物体的属性
💡 记忆口诀：Scene 是"世界"，Hierarchy 是"目录"，Project 是"仓库"，Inspector 是"属性面板"。

菜单栏概览

Unity 顶部菜单栏共有六大菜单，覆盖从文件到组件的全部操作：

菜单英文主要作用
文件File打开/保存场景、项目，创建游戏
编辑Edit复制粘贴、撤销，修改 Unity 部分属性设置（含快捷键）
资源Assets资源的创建、导入、导出与同步
游戏对象GameObject创建、显示游戏对象，建立父子关系
组件Component为游戏对象添加新组件或属性
窗口Window显示特定视图（项目/层级/检视等），管理布局

File（文件）

管理场景和项目文件：新建/打开/保存场景，创建新项目，以及最终的打包发布。

常用功能说明
New Scene新建场景
Open Scene打开已有场景
Save / Save As保存当前场景（Ctrl+S）
New Project创建新项目
Build Settings打包发布设置

Edit（编辑）

通用编辑操作和编辑器全局设置：撤销/重做、复制/粘贴、删除/复制物体，以及修改偏好设置。

常用功能说明
Undo / Redo撤销 / 重做（Ctrl+Z / Ctrl+Y）
Cut / Copy / Paste剪切 / 复制 / 粘贴
Duplicate复制物体（Ctrl+D）
Delete删除物体
Preferences编辑器偏好设置

💡 强烈建议掌握常用操作的键盘快捷键，能大幅提升编辑效率。

Assets（资源）

项目资源管理中心：创建脚本/材质/文件夹，导入外部资源包，导出项目资源。对应磁盘上的 Assets 文件夹。

常用功能说明
Create创建资源（脚本、材质、文件夹等）
Import Package导入资源包
Export Package导出资源包

GameObject（游戏对象）

场景中所有物体的创建入口：3D 基础物体（Cube/Sphere 等）、光源、音频、UI 元素、空物体等。搭场景从这里开始。

常用功能说明
3D Object（3D对象）创建 3D 物体（Cube/Sphere/Capsule 等）
Light（光源）创建光源
Audio（音频）创建音频源
UI（用户界面）创建 UI 元素（按钮、文本等）
Create Empty（创建空物体）创建空物体

Component（组件）

给游戏对象赋予行为：物理（Rigidbody/Collider）、渲染（Mesh Renderer）、自定义脚本——决定对象"能做什么"。

常用功能说明
Physics（物理）物理组件（Rigidbody、Collider 等）
Rendering（渲染）渲染组件（Mesh Renderer 等）
Scripts挂载自定义脚本

💡 记住：GameObject 是"东西"，Component 是"东西拥有的能力"。一个 Cube 加上 Rigidbody 组件，才会受重力掉落。

Window（窗口）

打开和管理编辑器各类视图面板：场景/游戏/层级/项目/检视/控制台，以及窗口布局的保存和重置。

常用功能说明
Scene / Game场景 / 游戏视图
Hierarchy / Project层级 / 项目视图
Inspector检视视图
Console控制台（调试信息）
Layouts窗口布局管理（重置布局）
各视图空间可拉伸 / 拖拽改变位置，玩乱了怎么办？

重置布局

  • 点击顶部菜单「窗口（Window）」→「布局（Layouts）」→「默认（Default）」，即可恢复默认布局

Project / Hierarchy / Inspector 三视图

① Project（项目视图）— 软件左下角

  • 包含整个工程所有可用资源（模型、脚本等）
  • 对应磁盘上的 Assets 文件夹，所有资源以目录方式组织，Unity 只认这个文件夹

② Hierarchy（层级视图）— 软件左上角

  • 显示当前场景中的每个游戏对象（摄像机、灯光、模型…）
  • 相当于 Photoshop 的"图层"概念：每个层可包含对象，其下可嵌套子对象，不断嵌套
  • 可在层级窗口把对象拖到另一个对象内，建立父子化（Parenting）

③ Inspector（检视视图）— 右侧

  • 本质就是"属性面板"：显示当前所选游戏对象 / 资源的属性与信息
  • 选中游戏对象 → 编辑位置 / 旋转 / 缩放等属性
  • 选中资源文件 → 修改导入设置（如贴图类型、压缩格式等）

Scene 场景视图 · Game 游戏视图 · 播放调试

游戏场景是怎么开发出来的？先在 Scene（场景视图） 中把对象（模型、灯光、特效等）布置进来，设置它们的位置、大小、旋转等信息，组成一幕画面。一个 Scene 只能组合出一幕画面，多幕画面则需要由多个场景构成——如战斗场景、欢迎场景、设置场景等，组合起来就是一个完整的游戏。

Scene（场景视图）

是游戏场景设计的主编辑区域，所有对象在这里布置（位置 / 大小 / 旋转），组成一幕画面。

一个 Scene 场景 = 一个独立的空间，场景文件是 Assets 下的 .unity 文件（如 SampleScene.unity）。

游戏可以由多个场景组成，通过脚本实现场景切换（地图切换）（如战斗场景、欢迎场景、设置场景等）。

Game（游戏视图）

是游戏运行时的显示窗口，对 Scene 的修改会实时同步过来。Scene 和 Game 是同一个窗口区域的两个 tab，可以切换查看。

Game 视图常见控件

Game 视图顶部常见控件：

  • Simulator 模拟设备：模拟不同设备运行（默认安卓），快速预览多端表现
  • Free Aspect 自由比例：控制显示比例 / 分辨率适配
  • 缩放：控制画面缩放倍数
  • Play Focused 运行聚焦：运行时让游戏视图抢占焦点，操作更流畅
  • 设备模拟 / 喇叭 / Gizmos / 状态栏：分别控制模拟环境、音频、辅助调试信息、实时状态（FPS / 渲染耗时 / 内存）

播放工具

（工具栏中央）：▶ 运行 / ⏸ 暂停 / ⏭ 单帧，用于编辑器内测试游戏。点 ▶ 运行后，Game 视图实时显示游戏画面。

控制台（Console）与状态栏

两个很有用的调试工具：

  • 状态栏在编辑器底部（通常是一条灰线）
  • 脚本里用 Debug.Log() 向控制台输出信息，有助于调试和修复错误
💡 写完脚本跑不起来？第一反应是看 Console 的红字报错，而不是猜。

场景视图详解（变换工具 · 坐标系 · 显示开关）

变换工具

变换工具（工具栏左侧）：查看 / 移动 / 旋转 / 缩放 / 矩形 / 变换组件，用来控制和操作场景及游戏对象，主要应用于 Scene 场景视图。

名称快捷键作用
查看工具 ViewQ平移 / 旋转摄像机视野
移动工具 MoveW移动选中的物体
旋转工具 RotateE旋转物体
缩放工具 ScaleR缩放物体
矩形工具 RectT2D / UI 元素排版
变换组件按钮Y移动/旋转/缩放游戏对象

Gizmo 坐标系工具

（Scene 视图右上角）：

  • Center / Pivot（中心 / 轴心）：改变游戏对象的轴心点——Center（中心）为包围盒中心，Pivot（轴心）为物体自身轴心
  • Global / Local（全局 / 本地）：改变坐标参考——Global（全局）为世界坐标，Local（本地）为自身坐标

Gizmo 导航器

Scene 视图右上角的 3D 坐标轴指示器，显示游戏世界的坐标系（左手系）：

  • 原点 (0, 0, 0)：世界坐标中心
  • Y 轴：上下（向上为 +Y）
  • X / Z 轴：东西南北（水平方向）
  • 左手系约定：X 向右、Y 向上、Z 向里（朝屏幕内），以后写 transform.position、做移动旋转都依赖它

2D / 3D 切换

2D 按钮：控制场景以 2D 还是 3D 方式显示，默认未选中是 3D；选中后场景以 2D 显示，摄像机视图变成平行视图。

渲染模式

渲染模式下拉框：选择场景的显示方式——实体方式 / Wireframe（线框）等，其它显示方式可以在引擎中试试。

光线按钮

光线按钮：控制场景是否显示真实角度的光线效果，不影响真实游戏的光线。

音频按钮

音频按钮：控制场景中是否播放音频，不影响游戏实际运行效果。

可见性与效果控制

控制其它物体在场景中是否显示（只针对场景视图，不影响游戏运行效果）：

  • Skybox 天空盒：控制场景是否显示天空盒
  • Fog 雾效：控制场景是否显示雾效果
  • Flare 镜头光晕：控制是否显示"镜头光晕"效果
  • Always Refresh 始终刷新：勾选后场景视图更"积极"地自动刷新画面
  • Post Processing 后期处理：控制是否显示"后期处理"效果
  • Particle Systems 粒子系统：控制是否显示粒子系统效果

Gizmos（可视化辅助）

  • 3D 图标：控制各类 3D 辅助图标的显示（变换 / 光源 / 相机 gizmos）
  • 淡化小工具：未被选中对象的辅助 gizmos 图标显示强度
  • 选择轮廓：选中对象的突出轮廓效果
  • 选择线：对象之间特定的选择关联线条
  • 地形调试警告：地形问题 / 不合理设置的调试警告

放大显示

放大显示：快捷放大某区域查看细节。
