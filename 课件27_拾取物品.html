本节学习目标

🎯用 WaitPickup 让道具悬浮浮动 + 旋转
🔍做魔法圈特效与「按F键拾取」提示框
📝用 PickupDetect（触发器 + 运动学刚体）检测靠近

✅用 PickupEvent + ItemManager 实现 F 键拾取

1. 悬浮道具

  1. 把一把枪拖入场景，重命名为 PickUpWeapon
  2. 挂 WaitPickup.cs：用 Mathf.Sin 控制上下浮动，用 Rotate 控制 360° 旋转
  3. 存成预制体，删除场景中的原物体
CSHARP
public class WaitPickup : MonoBehaviour {
    public float VerticalBobFrequency = 1f;
    public float BobbingAmount = 1f;
    public float RotatingSpeed = 360f;
    Vector3 m_StartPosition;
    void Start() { m_StartPosition = transform.position; }
    void Update() {
        float phase = ((Mathf.Sin(Time.time * VerticalBobFrequency) * 0.5f) + 0.5f) * BobbingAmount;
        transform.position = m_StartPosition + Vector3.up * phase;
        transform.Rotate(Vector3.up, RotatingSpeed * Time.deltaTime, Space.Self);
    }
}

2. 魔法圈与拾取提示

  1. 创建空对象 PickupItem，把道具作为其子物体随 WaitPickup 旋转
  2. 在 PickupItem 下加粒子系统 Magic circle 作魔法圈
  3. 在 GameUI 上建提示框 OperationPrompt（图像 + TextMeshPro PromptText，颜色 241,241,241,125），默认隐藏

3. 拾取检测

PickupItem 加碰撞体（勾选 Is Trigger）+ 刚体（isKinematic = true，运动学刚体让快速移动也能可靠触发）：

CSHARP
public class PickupDetect : MonoBehaviour {
    public GameObject pickupPrompt;
    public TextMeshProUGUI text;
    bool isTrigger = false;
    void Start() {
        var rb = GetComponent<Rigidbody>(); rb.isKinematic = true;
        var col = GetComponent<Collider>(); col.isTrigger = true;
        if (pickupPrompt) pickupPrompt.SetActive(false);
    }
    // c：走进拾取范围的物体（下面只认玩家）
    void OnTriggerEnter(Collider c) {
        if (c.tag != "Player") return;
        isTrigger = true;
        if (pickupPrompt) { pickupPrompt.SetActive(true); text.text = "按F键拾取"; }
    }
    // c：离开拾取范围的物体（下面用它清掉提示）
    void OnTriggerExit(Collider c) {
        if (c.tag != "Player") return;
        isTrigger = false;
        if (pickupPrompt) pickupPrompt.SetActive(false);
    }
}

5. F 键拾取（事件系统）

新增 PickupEvent，ItemManager 挂在 GameManager 上关注它；按 F 时 PickupDetect 广播拾取事件并销毁道具：

CSHARP
// Event.cs 新增
public class PickupEvent : GameEvent { public GameItem pickup; }
// PickupDetect.Update 中按 F：
if (Input.GetKeyDown(KeyCode.F)) {
    isF = true;
    if (pickupItem) {
        var evt = Events.PickupEvent; evt.pickup = item;
        EventManager.Broadcast(evt);
    }
    pickupPrompt.SetActive(false);
    Destroy(gameObject);
}
