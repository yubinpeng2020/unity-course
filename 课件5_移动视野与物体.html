变换工具总览

Scene 视图左上角的工具栏，从左到右依次是：

名称快捷键作用
查看工具 ViewQ平移 / 旋转摄像机视野
移动工具 MoveW移动选中的物体
旋转工具 RotateE旋转物体
缩放工具 ScaleR缩放物体
矩形工具 RectT2D / UI 元素排版
变换组件按钮Y移动/旋转/缩放游戏对象

查看工具：平移 · 聚焦 · 转动

按 Q 或直接点工具栏第一个图标，进入查看工具。掌握三种操作：平移、聚焦、转动。

临时切换：不论当前用哪个工具，按住鼠标滚轮不放拖动，临时变成查看工具，松开恢复

① 平移视野

按住鼠标左键拖动 → 视野跟着平移（上下左右看）

松开即停，场景位置不变，变的只是"摄像机看的角度"

② 聚焦物体（F 键）

场景中物体很多时，很容易"找不到刚才选的东西"。两个办法：

方法一：在查看工具下，左键点击物体，它自动移到视野中心

方法二（最常用）：先在 Hierarchy 或 Scene 中选中物体，按键盘 F 键，摄像机立刻"飞"到该物体旁边

💡 口诀：找不到物体？选中它，按 F，瞬间回到眼前。

③ 转动视野

转视野（绕当前中心）：按住 ALT + 鼠标左键拖动

绕物体旋转：先选中物体按 F，再 ALT + 左键

因为"绕谁转"取决于当前视野中心。先 F 聚焦物体，中心就在物体上，转的时候才是围着它转，而不是围着空气转。

第一人称转头：按住鼠标右键拖动，像 FPS 游戏里转视角

Gizmo 导航器与视角模式

Scene 视图右上角那个小坐标轴叫 Gizmo 导航器，它就是你的"指南针"——永远指示当前视角朝向。转动场景视野时，Gizmo 导航器会同步转动，所以无论怎么转，看一眼它就知道"我现在面朝哪边"。

  • Unity 使用左手坐标系：红 X（左右）、绿 Y（上下）、蓝 Z（前后）
  • 想象自己站在原点：X 是东西，Y 是上下，Z 是南北

常用操作

点击某个轴（如蓝色 Z）→ 立刻切换到该轴正视图

右键导航器 → 弹出菜单，选择顶视 / 前视 / 透视等

设置背景：右键菜单里可显示背景

锁定导航器：锁定后朝向不再被转动改变

恢复默认：按住 Shift + 点击导航器中间的小方块，回到初始透视角度

快速缩放：直接滚动鼠标滚轮，拉近 / 拉远

精细缩放：按住 ALT + 鼠标右键上下拖动，慢慢推拉，适合对齐细节

💡 快速缩放"粗"，精细缩放"细"。需要毫米级对齐时用 ALT+右键，别只靠滚轮。

透视 vs 正交视角

透视视角（Persp）：近大远小，符合人眼，但有广角畸变（广角越大，边缘越扭曲）

在 Scene 视图右上角点击 广角下拉框（默认约 60°），可手动调整广角大小：

  • 数值越小→广角越窄，畸变越少，但视野范围变小
  • 数值越大→广角越宽，视野更广，但边缘畸变更明显
  • 常用值：45°~60°（自然视角）、90°+（夸张广角效果）

正交视角（Iso）：没有近大远小，物体大小不随远近变，最适合做对齐

在 Gizmo 导航器（Scene 视图右上角坐标轴）下方，有一个视角下拉菜单：

  • 点击导航器下方的 Persp / Iso 文字标签，可直接切换透视 / 正交视角
  • 或点击导航器右上角的 ☰ 菜单按钮，在弹出菜单中选择「透视」或「正交」
💡 摆放、对齐物体时，一律切到正交视角；检查整体效果时再切回透视。

选中物体与移动工具

选中物体

  • 在 Scene 或 Hierarchy 中左键点击物体，它会出现橙色边框，表示已选中
  • 选中后，右侧 Inspector 检视视图 显示它的所有属性
是 Unity 的"选中标记"。有它，你接下来的移动 / 旋转 / 缩放才会作用在这个物体上。

Transform 变换组件

选中物体后，Inspector 顶部就是 Transform 组件，记录三个信息：

属性含义
Position 位置物体在 X/Y/Z 三个方向上的坐标
Rotation 旋转物体绕三轴的旋转角度
Scale 缩放物体在三轴上的大小比例
坐标系是左手系：X 左右、Y 上下、Z 前后。记住它，后面所有坐标都不迷路。
精确输入：直接在 Inspector 的 Position 框里填数字，毫米级精准。

移动工具（W）

按 W 或点工具栏第二个图标，进入移动工具。物体上出现 RGB 三色箭头（红 X / 绿 Y / 蓝 Z）。

  • 沿单轴移动：鼠标左键按住某根箭头拖动 → 只改那一个坐标

沿坐标平面移动

只拖一根箭头只能改一个坐标。想同时改两个坐标（比如保持高度不变，在地面上平移）？拖动箭头对应的彩色方块面（不是箭头）：

  • 拖 X 轴对应的面 → 改 Y 和 Z
  • 拖 Y 轴对应的面 → 改 X 和 Z
  • 拖 Z 轴对应的面 → 改 X 和 Y
因为很多摆放要求"贴着地面移动但高度不变"，用平面比用单轴方便得多。

一键归位 Reset

物体被你拖得乱七八糟？不用手动填 0：在 Inspector 的 Transform 右上角点击齿轮 / 小菜单 → 选 Reset，物体瞬间回到原点、零旋转、单位缩放。

💡 调乱了别慌，Reset 一键回出厂设置。

重叠处理

多个物体叠在一起看不清时，用查看工具或调整视角分开它们

💬 验收标准：把一个立方体从 (0,0,0) 精确移到 (3, 1, -2)，用输入框完成。

作业 — 四个物体并排

📌 承接上节课：把你在课件4中创建的 4 个物体（Cube / Sphere / Capsule / Cylinder）移动到 Plane 平面上，并排摆好。

要求：将 4 个物体并排摆在 Plane 平面上，满足以下三个条件。

要求一：正面横向分布

正交前视图 X 轴看：底端对齐，间隔 1 个单位

要求二：侧面左端对齐

正交左视图 Z 轴看：左端对齐

要求三：悬浮于平面上方

正交顶视图看：全部悬浮于平面上方

💬 提示：先切到对应正交视图，再用输入框精确给坐标，比纯鼠标拖快得多。

保存场景

  • 新建项目时，本地已有一个工程目录；"保存"实际是保存 Scene 场景 文件
  • 场景文件格式为 .unity，默认放在 Assets/Scenes 目录下（如 SampleScene.unity）
  • Ctrl + S 随时保存
⚠️ 实训室电脑每次关机还原，务必把工程存在不刷新的盘（如 D 盘），可以在下课前把成果拷贝走，避免丢失。
