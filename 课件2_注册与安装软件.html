注册与安装软件

注册 Unity 账号，下载并安装 Unity Hub、个人版许可证与 LTS 编辑器
授课教师彭堉斌
学校汕头职业技术学院

本节学习目标

🎯注册 Unity 账号并登录（网页端创建 / App 扫码 / 邮箱密码多种方式）
🔍安装 Unity Hub 并切换简体中文（实训室安装包 + 官网下载 两种方式）
📝登录 Unity Hub 并激活个人版许可证（每节课都要做）
💻安装 LTS 编辑器（本地安装包 / 在线安装 两种方式）
✅配置项目中文语言包（zh-hans.po）

动手前先搞懂两件事

本课动手前，先搞懂这两件事——它们决定你能否顺利装上、用好 Unity。

① 必须有 Unity 账号（一切操作的前提）

  • 下载和使用 Unity，都必须先有 Unity 账号
  • 账号是登录 Unity Hub、激活许可证、安装编辑器 的前提
  • 注册方式：在官网创建 Unity ID，绑定邮箱与手机即注册成功，注册后自动登录

② 实训室电脑：每节课都要重新配置（自己电脑只需一次）

  • 实训室电脑每次开机都会 还原系统，所以每节课都要重新：安装 Unity Hub → 激活许可证 → 配置编辑器
  • 💡 实训室电脑上老师会提前发放软件安装包，可直接使用，不用自己下载
  • 自己电脑只需安装一次，不受影响

注册 Unity 账号

① 访问官网，创建 Unity ID

  • 访问 https://unity.cn/ ，点击右上角个人图标
  • 选择"创建 Unity ID"，弹出注册窗口

② 填写邮箱与密码

  • 填写能正常收邮件的邮箱、设置密码等信息
  • 勾选所有协议要求，点击"创建"

③ 查收邮件并激活

  • 打开邮箱，找到 Unity 发送的新邮件
  • 点击邮件里的激活链接，等待加载完毕

④ 绑定手机，完成注册

  • 回到官网点击"继续"，填写手机号完成绑定
  • 导航栏图标改变样式，即账号创建并自动登录成功

登录 Unity 账号

注册后会自动登录；但重新打开电脑后仍需再次登录。

💡 强烈建议：装 App，扫码登录

登录方式有几种，首选扫码：手机装好 Unity 社区 App 并登录一次，以后在电脑上登录只要扫一下二维码——不用记密码、不用等邮箱验证码，机房换台电脑也不折腾。

下面的 ①② 照走（打开登录页、切到二维码那一栏），到选登录方式时直接选二维码，别再输账号密码。③④ 就是装 App 到扫码成功的过程。

① 官网点击"登录"

  • 访问 https://unity.cn/ ，点击个人图标，选择"登录"

② 选择登录方式

  • 可用邮箱 / 手机登录
  • 也可点击二维码，使用扫码登录（强烈建议走这条）

③ 扫码登录：先装 Unity 社区 App

  • 访问 https://developer.unity.cn/connectApp/download 扫码下载安装 Unity 社区 App
  • 用注册的 Unity 账号登录 App

④ App 扫码，完成登录

  • 打开 App，点击左上角扫码按钮，扫官网二维码
  • 登录成功，回到 Unity Hub 登录页面

安装与登录 Unity Hub

⚠️ 注意：Unity 中国推出了国产分支"团结引擎"，但我们学的是 Unity 2022 LTS 稳定版，下载时不要选错。原因：
① 版本稳定、国内外均可发布，省赛（数字化产品设计与开发、数媒游戏与交互设计）均基于 Unity；
② 团结引擎对国内小游戏 / 鸿蒙适配更好，但其工程（尤其场景文件）与 Unity 不能直接互通，生态与教程尚不成熟，不适合入门教学。
💡 实训室电脑每节课都要重装 Unity Hub（开机还原系统）；自己电脑只需安装一次。

Unity Hub 安装包（Windows 64 位）

  • 自己电脑安装 Unity Hub，可直接下载官方安装包：
  • 🔗 UnityHubSetup-x64.exe（点击下载，Windows 64 位）
  • 💡 实训室电脑已提供本地安装包，无需下载；自己电脑也可到 unity.cn/releases 下载

一、安装 Unity Hub

① 双击 UnityHubSetup-x64.exe 运行安装

  • 实训室：桌面文件夹数字产品设计实训课件 → "平台安装包"里找到 UnityHubSetup-x64.exe
  • 自己电脑：到 unity.cn/releases 下载 UnityHubSetup-x64.exe（Windows 64 位）
  • 双击运行，安装向导共三步：
  • 实训室直接装在 C 盘默认路径 即可；安装向导中点 Skip installation（本次只装 Hub，编辑器后续单独装）

二、登录账号

② 安装后自动打开 Unity Hub，点击 "sign in"

  • 安装完成会自动启动 Unity Hub，进入主界面

③ 跳转浏览器，显示扫码登陆

  • 浏览器自动打开 unity.cn 登录页
  • 已装 Unity 社区 App：点击 扫码登录，用 App 扫页面二维码（最便捷）

④ 切换到邮箱等登陆方式

  • 未装 App 时，在登录页切换到邮箱 / 密码方式登录

⑤ 登陆成功，提示打开 Unity Hub

  • 登录成功后页面提示"打开 Unity Hub"，回到主界面
  • 左上角头像由灰色变为彩色，说明登录成功

三、切换中文

⑥ 点击 agree（同意协议）

  • 首次打开如出现协议提示，点击 agree 同意

⑦ 点击 settings（设置）

  • 点击右上角"⚙️"打开设置面板

⑧ 点击 "Appearance" - "Language"，切换为 "简体中文"

  • 在设置面板切到 Appearance，把 Language 改为 简体中文，关闭面板

安装个人许可证

⚠️ 每次安装 Unity Hub 后都要重新激活许可证（实训室 每节课都要做）；自己电脑只需激活一次。许可证相当于使用授权签名。个人版免费、适合学习，但做出来的作品不能商用。

三种许可证

类型适用对象说明
个人版独立开发者 / 学习免费，功能有一定限制，不能商用
专业版专业游戏团队 / 公司功能全面、可商用，需付费
企业版大型企业面向企业级，需付费

① 打开许可证管理

  • 切换"许可证选项"，点击"添加许可证"

② 添加个人版许可证

  • 选择"获取免费的个人版许可证"（也可尝试申请学生版）

③ 同意并获取

  • 点击"同意"，获取个人版授权
  • 界面出现新的个人版许可证，即激活成功
💡 许可证有有效期，会过期；过期后重新申请即可，不影响已创建的项目。

安装 LTS 编辑器（方式一 · 本地安装包，实训室推荐）

LTS = 稳定版，bug 最少。实训室已提供本地安装包（UnitySetup64-2022.3.62f3c1.exe，约 3G）。

Unity 引擎下载

  • 自己电脑也可从官网下载 Unity 引擎安装包：
  • 🔗 unity.cn/tuanjie/releases
  • 操作步骤：点击「历史 Unity 版本」→ 选择「2022.3.62f3c1」→ 点击「下载 Win」→ 选择「Unity Editor 64-bit」

① 双击安装本地包

  • 双击 UnitySetup64-2022.3.62f3c1.exe 运行安装
  • 安装向导中连点三次 "Next"
  • 选择安装路径，建议安装在 D 盘，等待安装完成
  • 安装完成后点击 "Finish"
  • 记住安装的路径，后续要在 Hub 中指定该路径

② Hub 中添加本地编译器

  • 在 Unity Hub 左侧边栏切换到"安装"选项
  • 点击"选择位置"（Locate），指定本地编译器所在路径

③ 选择 Unity.exe

  • 找到编译器安装路径下的 Editor 文件夹，选择 Unity.exe

④ 配置完成并打开编译器所在文件夹

  • 在"安装"页面可以看到配置好的编译器，状态显示"编译器已配置"即成功
  • 💡 本地编译器只需添加一次（实训室 D 盘不还原）
  • 点击该编译器右上角的"管理" → "在资源管理器中显示"，可打开该编译器所在路径，确认文件完整

⑥ 设置项目中文语言包

  • 将老师提供的 zh-hans.po 文件，放到 Unity 编译器安装目录下的 Editor/Data/Localization/ 文件夹中
  • 💡 如果该路径下不存在 Localization 文件夹，可以自己新建一个
  • 💡 此步骤课件3 会再次提到，这里先提前配置好

安装 LTS 编辑器（方式二 · 在线安装，自己电脑）

① 修改下载路径

  • "设置" → "安装"，修改下载和安装路径（不要装 C 盘）

② 安装编辑器，选择 LTS 版本

  • 点击"安装编辑器"，选择 LTS 版本（课程要求 2022.3），点击"安装"

③ 勾选简体中文模块

  • 拉到最下面，勾选"简体中文"模块，点击安装
  • 等待安装完成，列表中出现所选编辑器
💡 安装后若需再加模块，可点击编辑器右侧设置 → "添加模块"。
