资源商店与模型资源

用 Unity 中国资源商店获取现成的场景、环境与角色模型资源，导入项目搭出一个有角色的小场景
授课教师彭堉斌
学校汕头职业技术学院

本节学习目标

🎯知道资源商店能拿到哪些资源（模型、环境、角色、天空盒、材质、音频、特效、工具），以及为什么现在要用 Unity 中国资源商店
🔍会用 Unity 中国资源商店（assetstore.u3d.cn）搜索并筛选免费资源，看详情判断是否适配
📝掌握「添加至我的资源 → 包管理器下载 → 导入项目」的完整流程（含 Unity 中国账号登录）
💻理解预制体（Prefab）与游戏对象的关系，会把导入的地形 / 天空盒 / 角色资源摆进场景，并修好材质发紫
✅能独立从资源商店获取天空盒 + 角色-人物 + 角色-动物资源，搭建并保存一个组合场景
📦网络不好时，会用本地资源包（.unitypackage）导入资源；也能把自己做的东西导出成包交给别人

为什么要用资源商店

自己做模型、画贴图、配材质，一个场景就要做很久。课件9 用的 Poly Haven 是免费模型站，而资源商店给的是"装进 Unity 就能用的成套资源"。

现在用「Unity 中国资源商店」

  • 2026 年 3 月 31 日起，海外 Unity 资源商店（assetstore.unity.com）不再向中国内地及港澳地区用户提供服务，免费和已购资源都无法再访问。
  • 现在改用 Unity 中国资源商店：https://assetstore.u3d.cn，用 Unity 中国账号登录（就是课件2 里注册的那个账号）。
  • 中国资源商店支持 Unity 2021 / 2022 LTS 和团结引擎，本课程用的 Unity 2022 LTS 在支持范围内。
  • 编辑器的「窗口 → 资源商店」菜单从 Unity 2020.1 起就已经被移除了，网上早些年的教程里那一步在现在的版本里不存在。
对比Unity 资源商店Poly Haven 等免费模型站
资源形态Unity 工程包：模型 / 材质 / 贴图 / 预制体 / 示例场景fbx 模型 + 贴图，自己拼
导入方式包管理器「我的资产」→ 下载 → 导入，不用离开编辑器下载压缩包 → 解压 → 拖进 Project → 修 NormalMap
与 Unity 的配合材质、Shader、比例都配好，拖进场景就能用常要自己配材质、开约束比例缩放、调朝向
资源类型环境、角色（带骨骼动画）、2D、特效、音频、工具，还有整套项目模板模型 / 贴图 / HDRI 三类
资源库账号里的「我的资源」记着获取过的资源，换电脑重新下载即可直接下载，没有账号库

资源商店的优越性

  • 直接给 Unity 用：下载下来就是 Unity 工程结构，预制体、材质都配好，拖进场景就能用，省掉"拼材质、调比例"的环节
  • 一步导入：获取 → 包管理器下载 → 导入，全程在编辑器里完成
  • 挑得明白：详情页标注支持的 Unity 版本、文件大小和内容清单，下载前就能判断能不能用
  • 要什么有什么：从环境、角色到特效、音频、工具都覆盖，Poly Haven 只有模型 / 贴图 / HDRI

商店里有什么

类别能拿到什么
3D · 环境场景地图、地形、建筑、道路、植被
3D · 角色人物/生物模型（很多带骨骼动画）
2D界面素材、图标、2D 角色与场景
视觉特效粒子特效、Shader
音频背景音乐、音效
工具编辑器增强、功能插件
模板完整项目框架（如 FPS 模板）

商店里既有付费资源，也有免费资源——免费资源完全够用来做课程项目。

登录 Unity 中国账号

打开 https://assetstore.u3d.cn（点链接直接在新标签页打开），右上角点「登录」，用课件2 注册的 Unity 中国账号进店。

① 打开链接，点右上角「头像」→「登录」

② 弹窗「登录 Unity 中国资源商店」：勾选「同意协议」，点「使用 Unity ID 登录」

③ 若已登录过 Unity 账号，会询问是否允许「Unity 中国资源商店」绑定该账号：点「允许」

④ 绑定后弹出「更新提示」：点「我已阅读并同意」

登录成功后，右上角会出现你的头像，就可以开始找资源了。

搜索资源

一、首页上找资源：搜索 · 分类 · 价格

首页上找资源，就靠这三个入口：

① 搜索框

  • 入口：首页顶部中间，中英文都能搜，边输边给搜索建议
  • 操作后：点「搜索」或按回车，跳到资源列表页，结果按资源卡片排开

② 分类入口

  • 入口：搜索框下面一排分类——角色（人物）、环境（天空）、3D（树木）、2D、AI Hub、官方资产、新手必备；「3D（树木）」下面再细分：着色器、树木、材质、纹理、载具、武器
  • 本质：点分类 ＝ 在搜索框里搜这个大类关键词，落到同一类资源的列表页（例：点「3D（树木）」→ 树木类资源）

③ 资源卡片

  • 入口：首页的卡片上有缩略图、资源名、标签；免费资源标「免费」，付费的显示价格和折扣
  • 操作后：点开卡片是资源详情页，价格（或「免费获取」按钮）在这一页

二、资源列表页：叠加筛选条件

在首页点「搜索」、点某个分类、点「查看更多」，都会跳到资源列表页——想看免费资源，就在这里加筛选条件：

右侧筛选栏

  • 价格 → 勾「免费资源」：结果里只留免费的
  • 条件还能叠加：具体大类 / 小类、Unity 版本 → Unity 2022.x、发布日期、发布者

添加至我的资源

以添加一个 地形 资源为例，把整条流程走一遍：

① 从大类进：「环境（天空）」→「地形」

  • 「分类」里点「环境（天空）」，再点「地形」，进入地形类资源列表

② 勾「免费资源」，挑一个目标资源

  • 右侧筛选栏 → 价格 → 勾「免费资源」，列表里就只剩免费的
  • 在结果里挑一个地形资源，点开它的卡片

③ 看资源的信息

  • 概述：确认支持的 Unity 版本里有 2022
  • 资源包内容：看文件大小和目录，判断包里有什么、值不值得下

④ 点「免费获取（添加至我的资源）」

  • 详情页点「免费获取（添加至我的资源）」，资源就记到账号下——这一步只是"拿到资格"，还没下载到电脑
  • 弹窗里点「我已阅读并同意」
  • 网页上显示「添加至我的资源」
  • 之后可以在商店右上角「我的资源」里核对

下载并导入到项目

回到 Unity 编辑器，把网页上获取到的资源真正下载到项目里：

① 打开包管理器

  • 菜单 窗口（Window）→ 包管理器（Package Manager），打开包管理器窗口

② 切到「我的资产」

  • 左上角下拉框把「包：内置」切换成「我的资产」——你账号获取过的资源都在这里

③ 下载并导入

  • 在「我的资产」列表里找到刚刚获取的 地形 资源
  • 先点「下载」把资源包拉到本地，下载完再点「导入」
  • 弹出确认窗口，再点一次「导入」才真正开始导入

④ 查看导入的资源

  • 导入完成后，Project 窗口的 Assets 下会多出一个资源文件夹，模型、贴图、预制体都在里面
  • 把资源拖进场景后，可能会发现材质全是紫色、没有内容——资源自带的 Shader 和本项目的渲染管线没对上，资源商店的资源常遇到这种情况

下一页我们讲怎么把这个地形资源用进场景，顺手把紫色材质修好。

如果「我的资产」列表是空的：检查编辑器右上角登录的是不是同一个 Unity 中国账号——账号不一致就看不到资源。

离线资源包 · 导入（Import Package）

资源商店要用网、要登录。机房网速慢、宿舍断网的时候，商店页面打不开、包管理器一直转圈、账号也登不上，手上的活就卡住了。

这时候走另一条路：老师提前把资源导出成一个资源包文件发下来，学生在 Unity 里导入——不用网、不用登录，进到工程里的东西和从商店下载的完全一样。

资源包里装的是什么

.unitypackage 是 Unity 自己的打包格式，把模型、贴图、材质、预制体，以及它们之间的引用关系一起装进一个文件。

  • 和课件9 的 FBX 不是一回事：FBX 只有网格和贴图，材质要自己重配、预制体要自己做
  • 导进去就是能用的状态：材质连着、预制体直接拖进场景就能跑

包从哪来、放哪

  • 从哪来：老师在工程里把资源导出成包（导出方法见页面8「导出资源包」），发到班级群或课程平台
  • 放哪：下载到电脑上任意文件夹即可，建议放在工程旁边的 资源包/ 里
  • 不用解压——它本身就是 Unity 的包，解压出来反而是一堆散文件，导不回去

这一课发下来的就是下面这四个包，正好对应作业要的三类资源加上地形：

包文件对应作业哪一类导入后在 Assets 下能看到什么
Stylized NPC.unitypackage
4.4 MB		角色-人物Stylized NPC - Peasant Nolant：4 个预制体、材质，还带一个 Demo 场景
Cartoon Animal.unitypackage
11 MB		角色-动物Cartoon Animal Pack 01：7 个预制体（6 只动物）、6 套动画控制器、一个演示场景

11 MB		天空盒M_ComicsSkybox：只有 1 个材质和它的贴图，换天空盒时把它填进 Skybox Material 就行

四个包加起来约 50 MB——一次导一个，导完看一遍再导下一个，别一口气全倒进工程。

① 两种导法：点菜单，或者直接拖

  • 走菜单：菜单栏 资源（Assets）→ 导入包（Import Package）→ 自定义包（Custom Package…），在文件对话框里选中那个 .unitypackage，点打开（Open）
  • 直接拖：把 .unitypackage 文件拖进 Project 窗口（拖到 Assets 里任意位置都行），松手后一样弹出导入窗口
  • 两条路走完弹出来的是同一个窗口，后面勾选、导入的步骤完全一样——哪个顺手用哪个

② 勾选内容，点「导入」

  • 弹窗把包里的文件全列出来，默认全部勾上——初学阶段不用挑，全选就行
  • 想全选点全部（All），想清空点无（None）
  • 点右下角导入（Import），包不大，几秒就完成

③ 导入后先看这三处

  • Project 窗口：Assets 下多出一个资源文件夹，位置和从商店下载的一样
  • 预制体：图标是蓝色方块，拖进场景就能用
  • 材质发紫：Shader 和渲染管线对不上，按页面9「使用地形资源」①改成 Standard

两条路，什么时候走哪条

对比资源商店本地资源包
要不要网要，还得登录账号不要，文件在手就能导
怎么拿网页获取 → 包管理器下载别人发给你，自己下载到本地
进工程的样子Assets 下一个资源文件夹一模一样
有没有记录账号里的「我的资源」记着获取过的资源没有，包丢了就得重找
⚠️ 把 .unitypackage 当成压缩包，是最常见的误会
它不能解压、双击也没反应，只能在 Unity 里走「导入包」这条路。包里也不带商店的获取记录，换电脑要用，就把包留好。

导出资源包 · 导出（Export Package）

反过来也有用：想把做好的东西带走——换台机器接着做、发给同学、交作业、请老师帮忙排查，都可以打包成一个 .unitypackage。

打包的对象是工程里的文件夹，既不是单个场景，也不是整个工程。

① 在 Project 里选中要打包的文件夹

  • 选中 Assets 下自己做的那个文件夹（例：Assets/我的场景）
  • 别直接选 Assets 本身——那样会把商店下载的资源、导入的模型全部打进去，包从几 MB 变成几百 MB

② 右键 → 导出包

  • 在选中的文件夹上右键 → 导出包（Export Package…）
  • 也可以走菜单栏 资源（Assets）→ 导出包（Export Package…）

③ 取消「包含依赖项」，再点导出

  • 弹窗列出文件夹里的全部内容，默认全勾
  • 把「包含依赖项（Include dependencies）」的勾去掉——勾着它，Unity 会把文件夹里用到的东西一路追进来，范围一下就失控
  • 点导出（Export），选个位置存成 .unitypackage

④ 对方怎么用

  • 拿到包的人走页面7「离线资源包」那三步：导入包 → 自定义包 → 全选 → 导入

三条要注意

  • 版本尽量一致：本课统一用 Unity 2022.3 LTS。高版本导出的包拿到低版本里打开，可能丢组件、报错
  • 只打自己做的东西：商店资源有授权限制，别人的包未必能用，体积还特别大
  • 依赖没打进去，对方会缺东西：预制体发灰、材质丢失，就是缺依赖；确实要一起发，就把相关文件夹一起选中再导出
💡 资源包是「离线快递」，不是备份
它只装你选中的那几个文件夹。整个工程要留底，还是整份拷贝，或者放进版本管理。

使用地形资源

地形资源导入后（页面6「下载并导入到项目」），先把它摆进场景当场地，再顺手把紫色材质修好，场地就能用了。

① 修复材质着色器（解决紫色）

  • 导入后材质发紫，是资源自带的 Shader 和本项目的渲染管线没对上——这是资源商店资源的常见现象
  • 在 Project 窗口选中发紫的材质，在 Inspector 里把 Shader 改成 Standard
  • 所有发紫材质都做同样处理，最后按 Ctrl + S 保存修改

② 了解预制体（Prefab）

  • 导入资源里的 Assets/资源名/Prefabs 下是预制体——它是已经配好模型、材质、缩放的"物体模板"，存在工程里可以反复使用

③ 使用预制体：把地形摆进场景

  • 把 地形预制体拖进 Hierarchy 窗口或场景视图，它就出现在场景里，作为你的场地地面

预制体的实例与模板关系（类比类与对象）

  • 把预制体拖进场景，就生成了一个游戏对象（GameObject）。这很像类与对象的关系：预制体相当于类（模板），场景里的游戏对象相当于按这个类 new 出来的对象（实例）
  • 改预制体 → 所有游戏对象一起变：在 Project 窗口改预制体，场景里所有由它生成的游戏对象会自动同步（就像改了类，所有对象都跟着变）
  • 改游戏对象 → 预制体不受影响：在场景里只改某一个游戏对象，这只是这个实例自己的覆盖（override），不会写回预制体——其他实例和模板都不变（就像只改某个对象，类本身不变）
  • 这节课用到的地形、建筑、树木都是预制体，拖一次就是一个游戏对象实例；想让所有同类物体统一变样，就去改预制体

下面两张检视器（Inspector）对比着看：左边选中的是预制体本身，右边选中的是场景里的游戏对象。注意游戏对象的检视器多了一块Prefab（预制体）区——它标着这个对象"来自哪个预制体"，还能把改动应用（Apply）回预制体；这就是实例和模板之间那条线的直观证据。

④ 添加地形道具：摆建筑 / 环境

  • 把环境预制体（建筑、树木、石头等）拖进场景，当作场地的道具
  • 选中场景里的物体，调 Position（位置）、Rotation（旋转）、Scale（缩放），摆到合适的地方
  • 物体别悬空、别互相穿插；按需取用，拖太多项目会卡

⑤ 嫌麻烦？直接用资源的 Demo 场景

  • 很多资源包会附带已经搭好的示例场景（Demo Scene），不想自己一点点摆地形、建筑、树木时可以直接用
  • 在 Project 窗口打开 Assets/资源名/Scenes，双击里面的任一 .scene 资源，就能打开一个现成的场景
  • 打开后可以整体参考，或删掉不要的部分、只留地形再继续——比从零搭省事，也不容易摆错

常见问题

地形显示成紫色（紫红色）怎么办？
资源自带的 Shader 和本项目的渲染管线对不上——按页面9「使用地形资源」①把材质 Shader 改成 Standard、全部材质改完后按 Ctrl+S 保存即可。
地形太大 / 太小、比例不对？
外部模型比例常和 Unity 不一致，用课件9学的约束比例缩放整体调整，别只拉一个轴。
「我的资产」里找不到刚获取的资源？
要么编辑器没登录 Unity 中国账号，要么资源还在同步（等几分钟刷新），要么资源已被发布者下架——换一个同类资源即可。
导入特别慢 / 卡住？
资源包大。下载前先在详情页看文件大小，课程作业选 100 MB 以内的就够；导入时不要同时做其他重活。
「导入包」里找不到「自定义包（Custom Package…）」？
看清楚别点到「导入新资源（Import New Asset…）」，那条是导单个图片 / 模型的。路径是 资源（Assets）→ 导入包（Import Package）→ 自定义包（Custom Package…）。
.unitypackage 双击没反应，是不是文件坏了？
不是。它不是能双击打开的压缩包，只能在 Unity 里走「导入包 → 自定义包」这条菜单进来。
导入后预制体发灰、场景里东西少了？
包里的依赖没打全。让发包的人重新导一次，导出时把相关文件夹一起选上（或保留「包含依赖项」）。

作业 · 在资源商店获取资源，搭"角色（人物 + 动物）+ 天空盒 + 地形"场景

基本要求

  • 选三类资源：在资源商店里选 天空盒资源、角色-人物、角色-动物（免费即可），各至少 1 个
  • 下载并导入：按页面6「下载并导入到项目」把三类资源下到工程
  • 网络不通怎么办：用老师发的离线资源包导入（做法见页面7「离线资源包」），判定标准不变——资源进到工程里、能摆进场景就算数
  • 更换天空盒材质：在场景里把天空盒换成你导入的那一套（Window → Rendering → Lighting → Environment → Skybox Material 选你的天空盒）
  • 加入角色预制体：把人物、动物资源里的预制体拖进场景，站在地形上（地形做法见页面9「使用地形资源」）
  • 组合场景：让人物 + 动物 + 天空盒 + 地形同时出现在场景里，比例自然、角色不悬空，按 Ctrl + S 保存

课件示例资源（任选，也可换别的）

作业要的三类资源加地形，课件里已经打包成四个离线包一起发下来了：有网就在商店里搜同名资源，没网就直接用这四个包——导进工程后是同一样东西，只是省掉了下载这一步。

  • 地形：Low Poly 免费低多边形自然森林资源包 (Free Natue Forest)　离线包 Pure Poly.unitypackage
